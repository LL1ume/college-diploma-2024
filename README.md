Short overview of the diploma project
Project title: Software system for an express delivery company  
Author: Holub Mykyta  
Educational institution: Kharkiv Professional Computer College  
Specialty: 121 Software Engineering  
Year of completion: 2025
Project description
This software product is my diploma (final) project. The main goal is to show how software can be used to organize the work of a small express delivery company.
The system includes three user roles:
- client (creating an account, placing a new order, viewing order history);  
- courier (viewing available orders, taking orders into processing, updating the order status until delivery);  
- manager (managing employees, viewing all orders, correcting order data if a mistake occurs).
The project consists of:
- a web application for clients, couriers and the manager;  
- a separate desktop application for the manager, which allows local work with the database even if there is no internet connection or electricity.
Main technologies
- Web part: PHP (server-side logic), CSS (user interface styling);  
- Desktop part: C# (Windows Forms);  
- Database: SQLite (managed via SQLite Browser).
Skills demonstrated in this project
- understanding of the full development cycle: from idea and modelling to implementation;  
- working with databases and user roles;  
- focus on business logic (orders, statuses, user roles);  
- ability to take real-life conditions into account (backup desktop solution for power or internet outages).
User interface language
The user interface of the system is in Ukrainian, as the project was developed and defended at a Ukrainian educational institution.
